# Oxion Plugin Starter Template

Fokus runtime plugin v1:

- TypeScript
- Python
- Elixir

Struktur template:

- `ts/manifest.json`
- `ts/src/main.ts`
- `ts/test/main.test.ts`
- `python/manifest.json`
- `python/src/main.py`
- `python/test/test_main.py`
- `elixir/manifest.json`
- `elixir/lib/main.ex`
- `elixir/test/main_test.exs`

- Gunakan permission minimum yang benar-benar dibutuhkan.
- Pastikan setiap keputusan plugin selalu mengembalikan `reason`.
- Jalankan test di staging sebelum enable di production.
